# 2026-05-12 Daily Work Log

## WebSocket Drop Investigation
Users complained that live WebSocket connections were dropping intermittently after ~60 seconds of inactivity when running behind reverse proxy / Cloudflare tunnel.

Root cause: Cloudflare and gateway proxies terminate idle TCP connections if no frame passes within 60s.
Fix: Set client/server WebSocket keepalive ping/pong interval to 45 seconds (`keepAliveIntervalMs = 45000`). Tested locally and drops stopped.

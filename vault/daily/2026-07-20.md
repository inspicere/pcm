# 2026-07-20 Daily Work Log

## Railway Private Networking Incident
Deployed server to Railway private networking. Services inside the private network mesh were failing healthchecks and unable to talk to each other.

Root cause: Railway internal private network uses IPv6 loopback addresses. If a Node.js/Bun server binds strictly to `0.0.0.0` or `127.0.0.1`, it only listens on IPv4, causing Railway's IPv6 internal proxy to fail connections.
Fix: Always bind server HTTP/WebSocket servers to `::` (or `[::]`) with `{ host: "::" }` to dual-stack IPv6 and IPv4.
